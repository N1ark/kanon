# tree-sitter-kanon

The [tree-sitter](https://tree-sitter.github.io) grammar of Kanon, for the
`.kn` and `.knl` files. It is the grammar of the Zed extension
(`editors/zed`), whose queries (`editors/zed/languages/kanon/*.scm`) are the
highlighting of the grammar here too.

The grammar follows `src/kanon_parser.mly`. It cannot see the operators that
other files declare, so an infix word (`infix "urem" = ...`) is an operator
where a name cannot be, between two patterns (`l urem #n`) or after an
operand that is not a name (`(x) urem y`); after a name, it is an argument of
an application (`x urem y` parses as `x` applied to `urem` and `y`).

## Development

```
npm install           # the tree-sitter CLI, in node_modules
npx tree-sitter generate
npx tree-sitter test  # test/corpus and test/highlight
npx tree-sitter parse ../modules/bool.kn
npx tree-sitter highlight ../modules/bool.kn
```

`src/` is generated by `tree-sitter generate`, and committed: Zed builds the
parser from it. CI checks that it is up to date, that the tests pass, and that
every `.kn` and `.knl` file of the repository parses without errors.

After changing the grammar, commit it, and set `rev` in
`editors/zed/extension.toml` to that commit (in a second commit): Zed fetches
the grammar at `rev`, and CI checks that it is the grammar of the checkout.
